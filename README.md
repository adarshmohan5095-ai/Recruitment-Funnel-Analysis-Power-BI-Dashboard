Recruitment Funnel Analysis – Power BI Dashboard

An interactive Power BI dashboard analyzing the recruitment pipeline from application to hire, covering funnel drop-off, source effectiveness, department performance, time-to-hire, and candidate-level tracking.

Overview

Built on a dataset of 100 applicants tracked across five recruitment stages (Applications → Screening → Interviewed → Offered → Hired), this project identifies where candidates are lost in the funnel, which sourcing channels convert best, and how long the hiring process takes at each stage.

Key finding: The steepest drop-off occurs between Applications and Screening — pointing to early-stage screening, not later interview or offer decisions, as the highest-leverage area for improving the overall 28% hire rate.

Dashboard Pages
Recruitment Overview – Core KPIs, hiring funnel, average time per stage, and department-level drop-off
Detailed Insights & Trends – Stage conversion rate, source effectiveness, an interactive decomposition tree, status breakdown, and application trend over time
Candidate Tracker – Record-level table tracing each candidate's full journey (application date, stage progression, days per stage, final outcome)

Insights & Recommendations
Early-stage screening is the primary funnel bottleneck, not interviews or offers
LinkedIn and Job Fair convert most efficiently per applicant, while Company Website drives the highest hire volume
Finance and HR post the strongest department-level hire rates; Marketing lags behind
Applications peak seasonally (April), useful for planning recruiter capacity
